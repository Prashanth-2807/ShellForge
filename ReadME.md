Week 1, established the foundation of the ShellForge project by:
•	Setting up the Linux development environment.
•	Creating a modular project structure.
•	Writing a simple interactive shell with a REPL loop.
•	Building the project using a Makefile.
•	Initializing a Git repository and pushing it to GitHub.
•	Creating the initial documentation.


## Week 2 Features

- Dynamic command input
- Memory allocation using malloc()
- Automatic buffer expansion using realloc()
- Proper memory cleanup using free()
